# Windows development

The Windows port is merged into `main`. Linux and Windows now share development,
tests and releases; the separate Windows branch has been retired.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the current Git and contribution
workflow, and [WINDOWS.md](WINDOWS.md) for Windows setup, building, tests and
portable packaging. Download the current Windows EXE from the
[latest release](https://github.com/evman/silage/releases/latest).
